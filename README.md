# Ucapan Ulang Tahun Kak Fia

Website ucapan ulang tahun 2 halaman untuk Kak Fia dari Adik Jihan.

## File
- `index.html` = halaman pembuka
- `page2.html` = halaman ucapan
- `style.css` = desain + animasi balon
- `script.js` = efek konfeti

## Deploy ke Vercel
1. Upload folder ini ke GitHub, atau gunakan Vercel CLI.
2. Di Vercel pilih **Add New Project**.
3. Import repository.
4. Framework Preset: **Other**.
5. Build Command: kosongkan.
6. Output Directory: `.` 
7. Deploy.

Tidak membutuhkan database atau backend.
